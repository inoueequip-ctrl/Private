01About

SOFT99 の高性能
ガラス系コーティング

コタキモータースでは、SOFT99 の高性能ガラス系コーティング「G’ZOX（ジーゾックス）」を採用しています。

お車の塗装状態に合わせた下地処理・ボディ研磨を行い、美しい光沢と優れた防汚性能を引き出します。
疎水タイプの「リアルガラスコート class H」と、撥水タイプの「リアルガラスコート class M」の2種類をご用意しております。

※販売車両につきましては撥水タイプの「リアルガラスコート class M」施工

すべてのコースに標準ボディ研磨・下地処理を含んだ、わかりやすい料金設定です

02Features

コーティングの特徴

G’ZOX リアルガラスコート

class H

HYDROPHILIC TYPE — 疎水タイプ

水がまとまって流れ落ちやすい疎水性能が特徴です。

ボディ表面に水滴が残りにくく、雨ジミや水アカの付着を軽減。落ち着いた美しい光沢を維持します。

こんな方におすすめ

  • 雨ジミや水アカが気になる方
  • 日頃のお手入れを楽にしたい方
  • 屋外駐車が多い方

G’ZOX リアルガラスコート

class M

WATER REPELLENT TYPE — 撥水タイプ

優れた撥水性能と深みのある艶が特徴です。

水滴を弾く美しい撥水効果に加え、ボディに透明感のある輝きを与え、塗装面を保護します。

こんな方におすすめ

  • 深みのある艶や光沢を重視する方
  • 水滴が弾く撥水効果を楽しみたい方
  • 愛車の美しい外観を長く保ちたい方

04Process

施工内容

当店のコーティング料金には、以下の作業が含まれています。

  1. 01ボディ洗車
  2. 02鉄粉除去・下地処理
  3. 03標準ボディ研磨（深い傷や重度のウォータースポットなどは標準研磨の対象外となる場合があります）
  4. 04脱脂・塗装面の仕上げ
  5. 05G’ZOX ガラスコーティング施工
  6. 06最終仕上げ・施工状態の確認

05Notes

施工料金についての
ご案内

  • 表示料金には標準的なボディ研磨・下地処理・コーティング施工費用が含まれています。
  • 車両の塗装状態、キズ、ウォータースポット、鉄粉や水アカの付着状況などにより、追加研磨・特殊処理が必要な場合は別途料金が発生することがございます。
  • 追加料金が発生する場合は、事前にお車の状態を確認し、お見積りをご案内いたします。
  • 車種・ボディ形状・サイズにより料金区分が異なる場合がございます。
  • 深いキズや塗装の劣化など、研磨では除去できない場合がございます。
